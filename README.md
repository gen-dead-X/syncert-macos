# Syncert desktop

An end-to-end encrypted, text-clipboard companion for macOS. Built with Tauri v2, React and TypeScript. The relay only sees ciphertext and routing metadata; the encryption key and device token live in the macOS Keychain, never in settings or logs. Windows and Linux are planned.

## Features

- Menu-bar/tray app, hidden from the Dock, launch at login and configurable global history shortcut (default `Cmd/Ctrl+Shift+V`).
- Polls text every 400 ms, with content deduplication and remote-item loop prevention.
- Skips macOS `ConcealedType`, `TransientType` and `AutoGeneratedType` clipboard items **without reading their text**. A Windows sensitive-format module and a Linux fallback are isolated in `src-tauri/src/platform/`.
- Creates spaces and pairs devices with QR or `syncert1:` text. Lists/revokes devices.
- Reconnect and offline/ciphertext retry queue; real-relay tests for fan-out and catch-up.
- Searchable local history: 50 items plus pinned items; click to copy.

**Do not use this as a password clipboard.** Sensitive markers depend on the source application; always treat clipboard history as sensitive.

## Run on your Mac

Prerequisites: macOS 12+, Xcode Command Line Tools, current stable Rust (1.90+), Node.js ≥22.14, pnpm 10.34.6. Verify `xcode-select --install`, follow https://rustup.rs for Rust, and use `corepack enable && corepack prepare pnpm@10.34.6 --activate` for pnpm.

```sh
git clone --recurse-submodules https://github.com/gen-dead-X/syncert-macos.git
cd syncert-macos
pnpm install
pnpm tauri dev
```

Click the tray icon or press **Cmd+Shift+V**. On first setup use a relay base URL such as `ws://localhost:8787` (not a `/ws` path). Create a space, then use **Devices → Generate pairing code** on the first computer and **Join existing space** on the second.

To run a local relay from the included core submodule:

```sh
pnpm --dir vendor/syncert-core --filter @syncert/server... build
node vendor/syncert-core/apps/server/dist/cli.js
```

Or in a separate checkout of [syncert-core](https://github.com/gen-dead-X/syncert-core), run `docker compose up --build`. For any non-local relay use `wss://`/HTTPS and expose it through your existing Tailscale/Tunnel setup.

### Verification

```sh
pnpm typecheck && pnpm build && pnpm test
pnpm test:integration   # starts actual Node relay and two headless engines
cargo test --manifest-path src-tauri/Cargo.toml
```

A macOS GitHub Actions workflow checks these and uploads unsigned `.app`/`.dmg` artifacts. It has not run yet because GitHub Actions is billing-locked on the owner's account. A macOS `.app`/`.dmg` cannot be built on Linux. Test the bundled app, Keychain permission prompts, NSPasteboard sensitive metadata, tray/Dock behavior, global shortcut and launch-at-login on a real Mac before use. The Rust cross-check on Linux is not a substitute for a native macOS build.

## Core dependency

Core is a **pin-able Git submodule** (`vendor/syncert-core`) included in one pnpm workspace. Its internal packages use `workspace:` dependencies, so installing a package from Git alone would be unreliable and submodules provide reproducible runtime and integration-test sources without npm publishing or per-package vendoring. Update it deliberately with `git submodule update --remote vendor/syncert-core`, then rerun the tests. The desktop branch tracks the core sync-engine branch until that PR is merged, then the gitlink should be updated to `main`.

See `docs/ARCHITECTURE.md` for platform/sync boundaries.
